Lab 2 · HTTP, requests in depth, hidden APIs and embedded data

The data you want is rarely in the HTML you see. It is in an official API, in a hidden API that the page's JavaScript calls, or in JSON hidden inside the HTML. Today you learn to find it, and to get it with a client that is fast, robust and polite.

Before you start

Put this lab2 folder inside ESILV_LAB. In a terminal in ESILV_LAB:

uv sync                    # once (or after an update of the lab)

How the projects work

The exercises are functions with raise NotImplementedError(...): read the docstring (what goes in, what comes out, examples) and replace the raise with your code. Then, in VS Code:

  • Click Run ▶ on check.py: ✅ done · ❌ wrong · ⬜ not done yet (NO internet needed: it uses samples/).
  • When everything is ✅, click Run ▶ on main.py: the real program, on the real website.

check.py never touches the internet: your functions receive a fake session that answers with the files in samples/. So every student can test as often as needed without sending one request to the websites. Run main.py only when check.py is all ✅, and not in a loop.

The rules of this lab

  • An honest User-Agent (at the top of each exercises.py). Never a copied browser User-Agent.
  • A timeout on every request, a pause between requests, the safety limits at the top of exercises.py.
  • The websites of this lab were chosen because their robots.txt allows these pages and their terms of use have no clause against robots (checked in November 2026). Before you scrape any other site, read both.
  • If you get 429 (too many requests): stop, wait several minutes. The whole class shares one IP address.
