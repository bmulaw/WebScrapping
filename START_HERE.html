New labs

Each day you get one new folder as a .zip file (lab2.zip, lab3.zip, …). Unzip it and put the folder inside this ESILV_LAB folder.

WindowsRight-click the .zip file → Extract All…
macOSDouble-click the .zip file.
LinuxRight-click the .zip file → Extract Here, or in a terminal: unzip lab2.zip

How to open a terminal inside ESILV_LAB

Most commands below must run inside the ESILV_LAB folder.

WindowsOpen the folder in File Explorer → right-click an empty space → Open in Terminal.
Or click the address bar, type powershell and press Enter.
macOSIn Finder, right-click the ESILV_LAB folder → New Terminal at Folder.
Or open the Terminal app, type cd and a space, drag the folder into the window, and press Return.
LinuxOpen the folder in your file manager → right-click an empty space → Open in Terminal.
Or in a terminal: cd ~/path/to/ESILV_LAB

Check: dir (Windows) or ls (macOS, Linux) must list pyproject.toml.

Before Day 2 · Python setup (once)

from Day 2
  1. Install uv (it also installs Python for you; you do not need to install Python yourself).
    WindowsIn PowerShell:
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    macOSIn Terminal:
    curl -LsSf https://astral.sh/uv/install.sh | sh
    If you use Homebrew, brew install uv also works.
    LinuxIn a terminal:
    curl -LsSf https://curl -LsSf https://astral.sh/uv/install.sh | sh
/install.sh | sh
    If curl is missing (Ubuntu / Debian): sudo apt install curl
    Close the terminal, open a new one, and check: uv --version
    macOS / Linux: if you see “command not found”, run source $HOME/.local/bin/env and try again.
  2. Install the lab packages. In a terminal inside ESILV_LAB (see above), on every system: 
    uv sync
    This creates a .venv folder with Python and everything the labs need.
  3. In VS Code: File → Open Folder… → choose ESILV_LAB.
    • In a notebook: click the kernel button (top right) → choose .venv.
    • For a .py file: open the command palette → Python: Select Interpreter → choose the one in .venv.
    WindowsCommand palette: Ctrl+Shift+P · interpreter: .venv\Scripts\python.exe
    macOSCommand palette: Cmd+Shift+P · interpreter: .venv/bin/python
    LinuxCommand palette: Ctrl+Shift+P · interpreter: .venv/bin/python
  4. Use the browser DevTools. In Day 2 you spend a lot of time in the Network tab: F12 (Windows, Linux) or Cmd+Option+I (macOS) → Network → filter Fetch/XHR.
